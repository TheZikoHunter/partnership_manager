# Gestionnaire des partenariats

**Projet réalisé pour :** Ministère de l’Éducation Nationale (Maroc)  
**Période :** Juillet 2024 – Août 2024

---

## Description

Cette application web a été développée pour gérer les partenariats au sein de la Direction Provinciale de l’Éducation. Le code utilise un mélange de PHP orienté objet et procédural.

Les principaux objectifs du projet sont :

1. **Simplicité** : l’application est conçue pour être utilisée facilement par des utilisateurs sans compétences techniques, notamment des locuteurs natifs arabophones.  
2. **Performance** : l’application fonctionne sur un serveur local avec connexion Ethernet, ce qui permet une bonne rapidité sans nécessiter d’optimisations réseau complexes.  
3. **Esthétique et contrôle des URLs** : un système simple de routage a été mis en place pour améliorer l’apparence des URLs et faciliter la gestion des différentes pages, notamment en cas d’erreurs ou d’exceptions.

---

## Fonctionnalités principales

- Gestion complète des partenariats avec une interface utilisateur intuitive  
- Routage personnalisé pour URLs propres et gestion des erreurs  
- Interface accessible pour utilisateurs non techniques, avec une conception centrée sur l’expérience utilisateur (UX)

---

## Technologies utilisées

- PHP (orienté objet et procédural)  
- MySQL  
- HTML / CSS  
- Routage personnalisé (sans framework)

---

## Installation et utilisation

1. Copier le dossier du projet dans le répertoire racine de votre serveur local (ex : `htdocs` pour XAMPP).  
2. Configurer la connexion à la base de données MySQL dans le fichier de configuration (`config.php` ou équivalent).  
3. Démarrer le serveur local (Apache et MySQL).  
4. Accéder à l’application via `http://localhost/nom_du_projet`.
